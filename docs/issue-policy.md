# 公开 Issue 规则

公开 Issue 只用于记录可公开的产品问题、抽象决策和可复核的代码任务。

允许写：

- 通用问题机制和用户任务假设；
- 脱敏后的业务抽象和虚拟数据字段；
- 代码文件、测试命令和公开文档链接；
- 已确认的架构边界与待决策项。

禁止写：

- 真实页面正文、截图、下载文件、登录后信息和接口响应；
- 真实个人、部门、地点、编号、联系方式和未公开规则；
- 本地路径、内部资料库位置、Token、Cookie、API Key 和 Trace 原文；
- 把“研究观察”或“痛点假设”写成学校已确认的事实。

需要引用真实来源时，只在本地私有研究记录中保存完整证据；公开 Issue 只保留抽象结论和来源类型，不复制来源内容。
